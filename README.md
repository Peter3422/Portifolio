## 🛠️ Executar localmente

Clone o repositório:

```bash
git clone https://github.com/Peter3422/Portifolio.git
```

Entre na pasta:

```bash
cd Portifolio
```

Depois, abra o arquivo `index.html` no navegador.

Para desenvolvimento, é recomendado utilizar o **Visual Studio Code** com a extensão **Live Server**.
